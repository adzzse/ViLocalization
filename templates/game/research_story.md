# Nghiên cứu game

Ghi tên game, phiên bản, ngôn ngữ nguồn và phạm vi dịch.
Dẫn nguồn bằng URL hoặc đường dẫn file + ID câu. Tách thông tin xác nhận, suy luận và chưa rõ.
Đọc văn bản trong game trước; đối chiếu nguồn chính thức khi cần bối cảnh.
